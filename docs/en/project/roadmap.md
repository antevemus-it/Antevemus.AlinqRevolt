# 🗺️ Roadmap

- [x] **v1.0.0**: `ALinqAsyncCollection` with `selectAsync()`, `whereAsync()`, `selectManyAsync()` and `eachAsync()` over the Revolt event loop (Fibers, Amp futures): an ordered, bounded, lazy window of items in flight, early stop that cancels what is in flight, errors and time limits at the item's position (`ALinqAsyncException`), and a core `ALinqLazyCollection` as the result, with the shape of its source declared, for every kind of source whose shape the core knows (it requires ALinq 2.3.0 for that). `RevoltRunner`, the concurrency limit with a per-item time limit, shareable between operators. The companion package of milestone 12 of the [ALinq roadmap](https://github.com/antevemus-it/Antevemus.AlinqCollection/blob/main/ROADMAP.md).
- [ ] **A policy for failures** (collect them, or skip the failed items) instead of stopping at the first one; 1.0.0 stops, and a closure can catch and return a value of its own.
- [ ] **An unordered variant** (`selectAsyncUnordered()`): results as they complete, so a slow item does not hold the window, when the order of the source does not matter.
- [ ] **A companion for another event loop** (ReactPHP, ...): not planned. It would be a separate package on the same hook of the core, touching neither the core nor this package, built on demand; what it implements is in [Architecture](../internals/architecture.md). Today a ReactPHP application runs this package through the adapter `revolt/event-loop-adapter-react`.

The milestone view of this list lives in [ROADMAP.md](https://github.com/antevemus-it/Antevemus.AlinqRevolt/blob/main/ROADMAP.md).
